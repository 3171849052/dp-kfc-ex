3. 把当前 two-backward BK 改成真正 one-backward BK
==================================================

当前 `expm1/bk.py::_one()` 有两个 backward：

第一次：
losses.sum().backward()

计算 clip factors 后又：
weighted_losses.sum().backward()

删除第二次 forward/backward。

每个 physical chunk 必须只执行一次 model forward + backward。

第一次 backward 后保留 raw activation/backprop：
a_i,l
δ_i,l

metric branch 只用于 norm。

DP-KFM：
a_m = a (A+λI)^(-β/2)
δ_m = δ (G+λI)^(-β/2)

DP-KFM-A：
a_m = a (A+λI)^(-β/2)
δ_m = δ

DP-SGD：
metric norm = raw norm，不重复计算同一个 Ghost norm。

DP-KFC：
保持当前 KFC metric definition。

利用 Ghost/BK identity 得到每个 sample 的 global norm 和：

c_i = min(1, C / norm_i)

然后直接使用第一次 backward 缓存的 RAW a, RAW δ 解析重建：

raw_sum = Σ_i g_i

clipped_raw_sum = Σ_i c_i g_i

绝对不再进行第二次 forward/backward。

Linear / ViT token Linear：
对 bias augmented activation 后：

weighted_b = b * c[:,None,None]
aggregate_matrix = einsum('bto,bti->oi', weighted_b, raw_a)

Conv：
继续 unfold，完全相同公式，然后 reshape 回 weight；
bias 使用 augmented activation 最后一维。

LayerNorm：
复用 exp22 中已有 per-example LayerNorm gradient 公式，
直接：
Σ_i c_i g_i

pos_embed：
einsum sample factor × token gradient

cls_token：
同样按 sample factor 聚合。

要求：
- 不 materialize full per-example parameter gradient
- 不进行第二次 backward
- raw_sum 可以直接来自第一次 backward 的 parameter.grad
- clipped_sum 必须由 BK cached activation/backprop + c_i 解析重建
- 每个 physical chunk `backward_calls == 1`

增加 correctness test：
toy Linear / Conv / LayerNorm：
BK clipped aggregate == explicit Σ_i c_i g_i

并 assert 正式 BK 每 physical chunk 只有一次 backward。

4. 修正 clipping / signal / update distortion 定义
==================================================

当前 DP-KFC 的 diagnostics 错误地先 transform raw reference，
这会把 KFC 本身的 optimizer-direction distortion 消掉。

统一定义：

g_raw = Σ_i g_i
g_clip_raw = Σ_i c_i g_i

机制真正使用的 signal：

DP-SGD:
g_signal = g_clip_raw

DP-KFM:
g_signal = g_clip_raw

DP-KFM-A:
g_signal = g_clip_raw

DP-KFC:
g_signal = KFC_transform(g_clip_raw)

必须记录三组不同指标：

A. clipping distortion，只测裁剪：
clip_cos =
cos(g_raw, g_clip_raw)

clip_rel_error =
||g_clip_raw - g_raw|| / ||g_raw||

B. mechanism signal distortion：
signal_cos =
cos(g_raw, g_signal)

signal_rel_error =
||g_signal - g_raw|| / ||g_raw||

这组指标用于直接检测 KFC preconditioning 改变优化方向，而 KFM 不做 preconditioning。

C. final private update distortion：
g_private = g_signal + noise

update_cos =
cos(g_raw, g_private)

update_rel_error =
||g_private - g_raw|| / ||g_raw||

所有这些均 research_only=true。

修改 mechanism.py / worker.py / analyze.py / CSV schema / plots。

新增或修改主图：
- clip_cos / clip_rel_error vs beta
- signal_cos / signal_rel_error vs beta
- update_cos / update_rel_error vs beta

DP-KFC 必须能显示：
raw gradient -> clipped raw gradient -> preconditioned signal -> noisy update
这三个阶段。

5. 修正 geometry anisotropy 指标，使其真正反映 beta
==================================================

当前 diagnostic_rows() 对原始 A/G 做 spectrum，
导致 condition_number 等基本没有 beta 的数学作用。

必须改成记录“实际 S_beta”的 spectral geometry。

对 damped eigvals：

a_j = eig(A) + λ
g_k = eig(G) + λ

DP-KFM：
shape block eigenvalues ∝ a_j^β g_k^β

因此：

condition_S =
(cond(A_damped) * cond(G_damped))^β

log_eigenvalue_spread_S =
β * sqrt(
    var(log a) + var(log g)
)

effective_rank_S =
effective_rank(a^β) * effective_rank(g^β)

DP-KFM-A：

condition_S =
cond(A_damped)^β

log_eigenvalue_spread_S =
β * std(log a)

effective_rank_S =
effective_rank(a^β) * d_out

tau 是全局 scalar，不影响 condition/effective rank，
但 trace_S 必须仍包含 tau。

同时保留 raw factor diagnostics，例如：
A_condition_raw
G_condition_raw
cosA / relative_error_A
cosG / relative_error_G

不要把 raw-factor anisotropy 和 actual S_beta anisotropy 混在一个字段。

`geometry_anisotropy_vs_beta.png` 必须使用实际：
condition_S
log_eigenvalue_spread_S
effective_rank_S

这样 beta=0 理论上趋向 identity geometry：
condition_S=1
log spread=0
effective rank=block dimension。

6. 修正 privacy sampling/accounting：改成真正 Poisson sampling
==================================================

不要继续使用：
shuffle=True + fixed-size batch
然后用 Poisson sampled Gaussian RDP accountant。

为了让正式论文中的 epsilon/delta 与 accountant 匹配，
private training 改成真正 Poisson subsampling。

对每个 task：

q = expected_batch_size / N
expected_batch_size = 256

每个 optimizer step：
每条 private record 独立以 probability q 被采样。

每 epoch 保持固定 step 数：
MNIST: floor(60000/256) = 234
ViT: floor(50000/256) = 195

总：
MNIST 1170
ViT 975

使用与当前 Opacus RDP accountant 一致的 Poisson sampling assumption。

可以复用 Opacus 合适的 Poisson batch sampler，
或者实现一个简单明确的 fixed-step Poisson batch sampler。

要求：
- 每一步 sampled batch size 可以变化；
- 不要求 len(batch)==256；
- physical chunking：
  MNIST max chunk=256
  ViT max chunk=128
- 最后一个 chunk 可以小于 physical batch；
- 不再要求 logical batch divisible by physical batch；
- noisy gradient SUM 最终除以固定 expected_batch_size=256，
  不除以本步 realized sample count；
- 每一步都执行 Gaussian mechanism 和 accountant.step；
- 极小概率 empty sampled batch 也定义为 zero clipped sum + pure Gaussian noise + optimizer step，
  不跳过该 privacy event；
- sampling RNG 与 model/noise/geometry RNG 独立且 deterministic per seed；
- config/metrics 记录：
  sample_rate=q
  expected_batch_size=256
  realized_batch_size mean/min/max per epoch

继续使用 remove-one adjacency。

checks 中验证：
- private sampler 是 Poisson/Bernoulli independent inclusion
- worker 不再使用 shuffle fixed-size loader 作为正式 privacy sampler
- accountant q 与 sampler q 完全一致
- divide denominator 固定 256
- steps 正确。

README 中删除任何 fixed-shuffle accountant 表述。

7. 优化 eigendecomposition，避免人为夸大 KFM runtime
==================================================

当前 Shape 对同一个 factor 重复：

matrix_power(...,-β/2)
matrix_power(...,+β/2)
eigvalsh(...) for trace
diagnostic spectrum(...)

导致一个 A/G 被重复 eigendecompose 多次。

重构成每 epoch 每 factor 只做一次 symmetric eigendecomposition。

例如：

SpectralFactor:
- eigenvalues_raw
- eigenvalues_damped
- eigenvectors
- metric_root = Q diag(lambda^(-β/2)) Q^T
- noise_root = Q diag(lambda^(β/2)) Q^T
- trace_power = Σ lambda^β
- raw diagnostics
- shaped diagnostics

full KFM 对 A 和 G 各一次 eigendecomposition；
KFM-A 只对 A 一次；
KFC A/G 各一次并得到 inverse sqrt。

不要为了 diagnostic 再重复 eigh。
