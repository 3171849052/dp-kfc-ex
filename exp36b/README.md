# Exp36b: Oracle KFC on ViT / CIFAR-10

This experiment measures the utility upper bound of accurate curvature information.
Oracle geometry uses unprivatized private CIFAR-10 training images; Full KFC also
uses their true labels. Oracle runs are **not deployable DP methods**. Their
`privacy_status = oracle_non_private_geometry` and `nominal_dp_epsilon = 3`
describe a research diagnostic: epsilon 3 describes only the subsequent Gaussian
training mechanism configuration, not an end-to-end privacy guarantee. Oracle
accuracy must not be reported as an effective epsilon-3 private model result.
The DP-AdamW baseline follows the existing standard DP protocol and accounting
convention (fixed shuffled batches, RDP accounting).

## Fixed protocol

Exactly three fresh runs: `dp_adamw`, `oracle_dp_kfc_a`, `oracle_dp_kfc`, seed 42.
Pretrained `vit_tiny_patch16_224.augreg_in21k_ft_in1k`, all parameters trainable,
5 epochs, AdamW lr 1e-4, weight decay .01, betas (.9,.999), eps 1e-8.
Logical batch 256, physical batch 128, clipping norm 1, nominal epsilon 3,
delta 1e-5. Data is read only from repository `data/`, download=False, bicubic
224x224 resize and mean/std (.5,.5,.5), no augmentation.

An isolated CPU generator seeded 42 selects the first 2560 indices of one
50,000-element permutation, saved in `results/oracle_indices.csv`. Every epoch
uses those same images in ten logical calibration batches of 256. Calibration
uses the identical training transform and an isolated loader generator, without
changing private shuffle or DP noise RNG. Calibration physical batching follows
Exp22 (256). Private shuffle seed is 42; DP noise seed is 40042.

A-only uses the original bias-augmented Exp22 covariance builder and Exp35 raw
spectral operator `(A + .001 I)^(-.4)`, outer scale 1. There is no RMS matching,
spectral normalization, mixing or gain cap. Full KFC uses the original Exp22
builder with real labels substituted at its label-input boundary, and inverse
square roots `(G + .001 I)^(-.5)` and `(A + .001 I)^(-.5)`.
Linear tokens flatten to `(B*T,d)` exactly as in Exp22. Calibration backward
clears gradients, never calls an optimizer and never updates parameters.

The unchanged Exp30 loop rebuilds geometry each epoch, computes private
per-example gradients, transforms geometry, clips globally, aggregates, adds
isotropic Gaussian noise and updates AdamW, in that order. Exp22 supplies the
pretrained model conversion and BK engine. Exp35 supplies metrics enrichment,
raw A operators, data preprocessing and cached pretrained checkpoint copying;
Exp35b supplies isolated runtime setup. Runtime dependency binding changes no
existing source. All new caches, logs and results stay inside `exp36b/`.

## Run

From repository root, using physical GPU 0, sequential fresh processes:

```bash
conda run --no-capture-output -n curve bash exp36b/run_all.sh
```

No sweeps, automatic resume or batch adjustment. Each run writes config.json
before initialization/training and metrics.csv each epoch under `results/runs/`.
Metrics retain all reference group/layer norms, clipping and norm quantiles,
step counts, finite/update checks and operator storage. A-only also reports
gain p10/p50/p90/p99/min/max. Full KFC has no artificial scalar gain metric.
The entry point uses the existing Exp30 checkpoint read-only as its copy source.

## Checks and analysis

```bash
conda run --no-capture-output -n curve python -B exp36b/checks.py
bash -n exp36b/run_all.sh
```

Checks use real CIFAR inputs and a tiny CPU classifier, not a formal training
run. They validate subset identity, labels, explicit covariance and operator
formulas, token flattening, no parameter changes and cleared gradients.

After all three runs, analyze.py writes summary.csv, oracle_vs_synthetic.csv,
layer_family_norm_ratios.csv and figures for accuracy, loss, clipping, p90/p99
norms and every ViT group norm. Historical comparisons read the seed-42 raw pink
A-only run from `exp35/results/vit/runs/dp_kfc_a_raw` and the pretrained Full KFC
run from `exp22/results/runs/dp_kfc_42`; older small-model `formal_bs256` results
are excluded. Historical sources are read only, with model/batch/seed checks.
Each family ratio sums squared layer RMS norms and takes the square root,
then divides by the current DP-AdamW family's norm at the same epoch. Families
are attention qkv, attention out_proj, MLP fc1, MLP fc2 and patch/head. These
ratios compare the respective trained trajectories, not a shared model state.
No formal results are generated by the checks.
